First public release of **FreeTubium** - a fast, modern desktop app for downloading video and audio from YouTube and ~1800 other sites, powered by a bundled `yt-dlp` + `ffmpeg`. No Python, no command line, no separate installs.

## Downloads

Pick the installer for your platform:

| Platform | File |
| --- | --- |
| Windows 10 / 11 (x64) | `FreeTubium_0.1.0_x64-setup.exe` (recommended) or `FreeTubium_0.1.0_x64_en-US.msi` |
| macOS (Apple Silicon) | `FreeTubium_0.1.0_aarch64.dmg` |
| macOS (Intel) | `FreeTubium_0.1.0_x64.dmg` |
| Linux (x64) | `FreeTubium_0.1.0_amd64.AppImage` or `FreeTubium_0.1.0_amd64.deb` |

## Highlights

- Paste a link, see title, thumbnail, duration, and the formats it actually offers, then download with live progress, speed, and ETA
- Quality picker (Best / 8K / 4K / 1440p / 1080p / 720p / 480p) and container choice (MP4, MKV, WebM)
- Audio-only extraction to MP3, M4A, or Opus
- Full playlist analysis with per-item selection
- Download queue with configurable concurrency, pause/resume, cancel, and retry
- Searchable download history, dark and light themes, clipboard watcher
- Subtitle download/embedding, thumbnail cover art, metadata tagging
- One-click self-update for the bundled `yt-dlp`

## Note on security warnings

These builds are **not code-signed**, so your OS will warn on first launch:

- **Windows SmartScreen:** click **More info -> Run anyway**
- **macOS Gatekeeper:** right-click the app -> **Open**, then confirm

Nothing is wrong with the download - the OS simply cannot verify who built it. If you prefer, [build from source](https://github.com/TheEvalon/FreeTubium#development).
